# External Integrations

**Analysis Date:** 2026-06-02

## APIs & External Services

None. This is a self-contained desktop simulation tool with no network calls, cloud services, or external API integrations.

## Data Storage

**Databases:**
- None. All persistence is flat files on the local filesystem.

**File Storage:**
- Local filesystem only.
  - Input parameter files: `setup parameters/*.json`
  - Simulation output: `simulation_results/DD_MM_YY_N/run_N/result.csv` + `config.json`
  - Checkpoint state: `simulation_results/.../checkpoint.npz` + `checkpoint.json`
  - Atom initial-condition samples: `starting condition samples/*.csv`
  - Atom snapshots (debug): `snapshot_initial_conditions.csv`, `oven_snapshot_initial_conditions.csv` (written to repo root by `src/parameters.py`)

**Caching:**
- Numba JIT compilation cache: stored as `.nbi`/`.nbc` files inside `src/__pycache__/` and `src/interaction_wrappers/__pycache__/`. Populated automatically on first run; subsequent runs load from cache.

## Input Data Formats

**Simulation parameters — JSON:**
- Format: JSON, validated against JSON Draft-07 schema at `GUI/schema/schema_v1.json`
- Examples: `setup parameters/Hammel_Setup.json`, `setup parameters/Tiecke_Setup.json`
- Top-level keys required: `Atoms`, `Magnetic_Fields`, `Lasers`, `Boundaries`, `Simulation`
- Loaded by: `src/parameters.py` (`Parameters.__init__`)

**Atom initial conditions — CSV:**
- Location: `starting condition samples/*.csv`
- Columns: atom positions and velocities (read via `pd.read_csv` in `src/parameters.py`)
- Used when `sample_style` is `"oven"` or `"sample_file"` in the parameter JSON
- Generated by: `GUI/workers/oven_worker.py` (Maxwell-Boltzmann sampler) or captured as snapshots

**Experimental reference data — CSV:**
- Example: `Experimental PB Vel.csv` (push-beam velocity data, used in `plots.py` for comparison)

## Output Data Formats

**Per-step simulation results — CSV:**
- Path: `simulation_results/DD_MM_YY_N/run_N/result.csv`
- Written by: `src/batch_worker.py` (buffered line-by-line, buffer flushed every 10 000 lines)
- Columns: per-atom step, position (x/y/z), velocity (x/y/z), subjective time, excitation count, groundstate
- Header written on first flush; subsequent flushes append raw lines

**Run configuration copy — JSON:**
- Path: `simulation_results/DD_MM_YY_N/run_N/config.json`
- Written by: `src/batch_worker.py` after each run completes
- Content: verbatim copy of the input parameter JSON

**Batch summary — JSON:**
- Path: `simulation_results/DD_MM_YY_N/_trapped_summary.json`
- Written per batch by `BatchSimulationWorker`

**Checkpoint files — NPZ + JSON:**
- Paths: `simulation_results/.../checkpoint.npz`, `simulation_results/.../checkpoint.json`
- `checkpoint.npz`: compressed NumPy archive of all per-atom arrays (positions, velocities, groundstates, status, time clocks, counters) — written via `np.savez_compressed`
- `checkpoint.json`: batch progress metadata, current step, NumPy RNG state (pickle + base64), format version
- Managed by: `src/checkpoint.py`

**Atom snapshots — CSV:**
- `snapshot_initial_conditions.csv`, `oven_snapshot_initial_conditions.csv` (repo root)
- Written by `src/parameters.py::write_atoms_to_csv` via `pd.DataFrame.to_csv`

**Plots — PNG / interactive matplotlib:**
- `util/heatmaps/*.png`, `util/spectra/*.png` — generated by `plots.py`, `util/integrated_spectrum.py`
- In-GUI plots embedded via `FigureCanvasQTAgg` in `GUI/widgets/features/sample_generator.py` and `GUI/widgets/features/spectrum_tab.py`

## Physical Constants

**scipy.constants (`scc`):**
- Used throughout `src/` as the authoritative source for all physical constants (speed of light, Planck/Boltzmann constants, atomic mass unit, Bohr magneton, etc.)
- Imported as `scc` in: `src/atoms.py`, `src/interactions.py`, `src/magnetic_field.py`, `src/absorption_and_emission_process.py`, `src/distributions.py`, `src/spectrum_kernel.py`, `src/parameters.py`, `src/maxwell_boltzmann_sampler.py`, `src/interaction_wrappers/*.py`
